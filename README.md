# Скрипты для извлечения файлов из ZIP-архивов Google Фото

Этот репозиторий содержит два скрипта для извлечения фотографий (`.jpg`) и видео (`.mp4`) из ZIP-архивов, созданных сервисом **Google Фото**. Скрипты автоматически фильтруют и извлекают только нужные файлы, игнорируя метаданные (`.json`).

## Скрипт 1: `script_v1.py`

### Описание
Этот скрипт использует метод `extract` из библиотеки `zipfile` для извлечения файлов. Он прост в использовании, но менее оптимизирован для больших объемов данных.

### Особенности
- Извлекает файлы с расширениями `.mp4` и `.jpg`.
- Исключает файлы, содержащие `.json` в названии.
- Логирует процесс извлечения и ошибки.
- Измеряет время выполнения.

### Пример использования
```bash
python src/script_v1.py
```

### Время выполнения
- Время выполнения: **0:31:57.554542**
- Количество фото: **9961**
- Количество видео: **684**

---

## Скрипт 2: `script_v2.py`

### Описание
Этот скрипт оптимизирован для работы с большими объемами данных. Вместо использования метода `extract`, он читает и записывает файлы по частям (чанкам), что уменьшает использование памяти и ускоряет процесс.

### Особенности
- Использует буфер размером **4 KB** для чтения и записи файлов.
- Извлекает только файлы с расширениями `.mp4` и `.jpg`.
- Исключает файлы, содержащие `.json` в названии.
- Логирует процесс извлечения и ошибки.
- Измеряет время выполнения.

### Пример использования
```bash
python src/script_v2.py
```

### Время выполнения
- Время выполнения: **0:23:57.554542** (с буфером 4 KB)
- Количество фото: **9961**
- Количество видео: **684**

| Характеристика          | `script_v1.py`         | `script_v2.py`         |
|-------------------------|------------------------|------------------------|

## Установка и запуск

1. Убедитесь, что у вас установлен Python 3.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/MrTimofeev/Copy_from_zipfile
   ```
3. Перейдите в директорию с проектом:
   ```bash
   cd Copy_from_zipfile
   ```
4. Запустите нужный скрипт:
   ```bash
   python src/script_v1.py
   ```
   или
   ```bash
   python src/script_v2.py
   ```
